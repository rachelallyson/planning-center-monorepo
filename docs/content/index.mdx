# Planning Center API Clients

TypeScript client libraries for Planning Center Online (People and Check-Ins) APIs.

## Packages

This monorepo contains three packages:

### [People API Client](./concepts#people-package)
**Package**: `@rachelallyson/planning-center-people-ts`

Complete TypeScript client for Planning Center People API with 11 modules: people, fields, workflows, contacts, households, notes, lists, campus, serviceTime, forms, reports. See [Quick Start](./guides/quickstart) and [API Reference](./api/) for usage.

### [Check-Ins API Client](./concepts#check-ins-package)
**Package**: `@rachelallyson/planning-center-check-ins-ts`

Complete TypeScript client for Planning Center Check-Ins API: events, check-ins, locations, event times, stations, labels, options, and more. Same patterns as People (getAll, getPage, getById, create, update, delete).

### [Base Package](./concepts#base-package)
**Package**: `@rachelallyson/planning-center-base-ts`

Shared infrastructure for PCO API clients: HTTP client, auth, rate limiting, pagination, error handling, JSON:API types. Use when building custom clients.

## Quick Start

### Installation

```bash
# People API Client
npm install @rachelallyson/planning-center-people-ts

# Check-Ins API Client
npm install @rachelallyson/planning-center-check-ins-ts

# Base Package (for building custom clients)
npm install @rachelallyson/planning-center-base-ts
```

### Basic Usage

```typescript
import { PcoClient } from '@rachelallyson/planning-center-people-ts';

// Option 1: Environment variables (recommended)
const client = new PcoClient({
  auth: {
    type: 'personal_access_token',
    personalAccessToken: process.env.PCO_PERSONAL_ACCESS_TOKEN!
  }
});

// Option 2: Direct configuration (convenient for development)
// const client = new PcoClient({
//   auth: {
//     type: 'personal_access_token',
//     personalAccessToken: 'your_client_id',
//     personalAccessTokenSecret: 'your_client_secret'
//   }
// });

// Find or create a person
const person = await client.people.findOrCreate({
  first_name: 'John',
  last_name: 'Doe',
  email: 'john@example.com'
});

console.log(`Person ID: ${person.id}`);
```

**See [Quick Start Guide](./guides/quickstart) for complete Personal Access Token setup instructions.**
