# PCO API Vertices

Static snapshot of the **People** and **Check-Ins** API vertex docs from [developer.planning.center](https://developer.planning.center/docs/). Includes Attributes, Query By, Can Include, Order By, and Filter By for each vertex.

**[Open PCO API vertices →](/vertices/index.html)**

Use the link above to browse the combined vertex reference (People and Check-Ins). Bookmark `/vertices/index.html` for direct access. The content is generated by `npm run docs:export-vertices` from the repo root.
