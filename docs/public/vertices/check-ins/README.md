# Check-Ins API vertices (static snapshot)

Static HTML snapshot of the PCO Check-Ins API vertex docs. Generated by `npm run docs:export-check-ins-site` from the repo root.

- **View:** Open `index.html` in a browser, or run a local server (e.g. `npx serve .`) and open the root URL.
- **Content:** Each vertex page uses the real HTML and CSS from [developer.planning.center](https://developer.planning.center/docs/#/apps/check-ins/2025-11-10/vertices/); styles load from the PCO docs origin when online.
